## MPFB2 (MakeHuman Plugin for Blender) — candidate pipeline
Source: https://github.com/makehumancommunity/mpfb2/blob/master/LICENSE.md
- Addon source code: GPLv3 (program logic only; does not taint output).
- Bundled assets (base mesh, proxies, targets, textures, clothes, rigs, poses,
  expressions, JSON mesh data): CC0 1.0 Universal.
- Generated output (exports FBX/OBJ/GLB, rendered data, saved models): the
  MakeHuman team makes no claim; output = CC0 assets + our creative input.
  → No restriction on use, including a possible later paid tier. Accurate
  statement: "MPFB-generated characters are unencumbered", NOT "CC0-ish".
- Blender: GPL application; generated output files are the user's data.
- TalkingHead (met4citizen): MIT; its bundled MPFB example avatar is CC0.
- Viseme/ARKit blendshape injection per TalkingHead blender/MPFB/MPFB.md
  (Visemes 02 + Faceunits) — required for lipsync.
- Character must be an invented person (no real person's likeness, no Oliver
  photos anywhere in the pipeline).
