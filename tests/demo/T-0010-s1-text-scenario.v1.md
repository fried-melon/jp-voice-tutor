# T-0010 데모 시나리오 — S1 편의점 포인트 카드 (텍스트 입력, v1)

목적: 음성 인식(ASR)과 분리해, 대화 로직(안내 → 질문 → 응답 판정 → 마무리)과 세션 기록 저장을
텍스트 입력으로 끝까지 검증한다. 모든 일본어는 content/lessons.v1.json M1-S1과 앱 기존 표현만 사용
(새 일본어 교재 문장을 만들지 않음). 이 시나리오가 만드는 DB 행은 합성 데모 데이터이며 session_id와
시각으로 실사용 기록과 구분한다.

레슨: M1-S1 「포인트 카드」 — 목표: 없다고 답하기
- 점원 질문: ポイントカードはお持ちですか。
- 목표 답: 持っていません (인정 변형: ありません / ないです / いいえ、持っていません / いいえ)

## 턴 스크립트와 통과 기준

| # | 입력 (학습자) | 기대 응답 (통과 기준) |
|---|---------------|----------------------|
| 0 | (세션 시작) | 한국어 시작 안내 1회(상황·역할·목표) + 점원 질문 ポイントカードはお持ちですか。 안내는 이 세션에서 정확히 1번만 |
| 1 | もう一度お願いします | 목표 칭찬 금지. 점원 질문을 다시 들려주는 것으로 응답 |
| 2 | 없어요 | 목표 칭찬 금지 (규칙 11: 일본어 목표 발화·인정 변형 없이 칭찬 금지). 한국어 도움 요청으로 처리해 持っていません 로 안내 |
| 3 | 카드 없어요 | 목표 칭찬 금지 (규칙 6-1: 한글 섞인 입력은 인식 실패 경로). 재질문 또는 힌트 「持って…」 로 응답 |
| 4 | 持っていません。 | 목표 달성 칭찬 + 마무리 안내(closing: 점원이 카드를 물으면 이제 답할 수 있어요 계열) |
| 5 | (세션 종료) | 저장 완료 표시 '서버에 저장됐어요' 확인 |

## 검증 포인트 (단계 매핑)
- 2단계: 턴 0~4로 5턴 이상 교환, 화면 캡처와 자막 로그 확보
- 3단계: 턴 1~3이 모두 칭찬 대신 재질문·정정·안내로 응답 (3/3)
- 4단계: 종료 후 학습 DB에서 이 세션 1건 확인 (sessions + transcript_entries + session_notes_snapshot)
- 5단계: 캡처 자료를 산출물 폴더 문서로 정리

## 합성 데이터 표기
실행 시각과 session_id를 결과 보고에 기록해, 대표의 실제 학습 기록(Nov 13 세션 1건)과 구분한다.
